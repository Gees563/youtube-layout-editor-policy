YouTube Layout Editor プライバシーポリシー

対象バージョン: 0.18.2・0.22.0／文書更新日: 2026年10月23日

YouTube Layout Editor（以下「本拡張機能」）は、YouTubeの表示レイアウト、弾幕表示、NGフィルターを利用者の端末上で動作させます。本拡張機能はYouTubeまたはGoogleの公式製品ではありません。

1. 処理する情報

本拡張機能は、YouTube動画ページ・ライブチャットページに表示される動画タグ、コメント、チャット本文、表示ユーザー名等を、表示調整・NGフィルター・弾幕表示のために読み取ります。

また、利用者が設定したレイアウト設定、弾幕設定、NGワードおよびNGユーザー名の照合条件、表示言語（日本語・英語）をChromeのローカルストレージに保存します。NGユーザー名の設定は表示名による照合であり、アカウントIDを追跡する機能ではありません。本文や表示名はフィルター判定・弾幕表示のために画面上で参照し、コメント・チャットの全文履歴を拡張機能の設定として保存しません。

2. 利用目的

読み取った情報は、通常動画の表示配置の変更、動画タグ表示・コピー、ライブ・アーカイブの弾幕描画、NG条件によるコメント・チャットの非表示に利用します。投稿の削除・通報は行いません。

3. 外部送信・第三者提供

本拡張機能は、取得したチャット、コメント、NG設定、閲覧履歴などを開発者のサーバーや外部の解析サービスに送信しません。広告配信やデータ販売の機能も含まれていません。YouTube自体による通信やデータ処理はYouTubeの規約・プライバシーポリシーに従います。

4. 保存と削除

設定は利用者のブラウザ内に保存されます。「その他」タブから設定をJSONファイルとして手元にバックアップ・復元できます。設定の初期化によりNG条件を含む保存設定を初期状態に戻せます。拡張機能の削除によって保存設定が消える場合があります。バックアップファイルは利用者自身で管理してください。

5. 使用する権限と対象ページ

storage権限を設定保存のために使用します。本拡張機能のコンテンツスクリプトは www.youtube.com 内で動作し、YouTubeのホーム画面などから動画視聴ページへの移動を検出して機能を安定して起動します。レイアウト編集は通常動画を対象とし、ライブ配信・アーカイブでは弾幕表示やNGフィルターを提供します。他のWebサイトを横断して閲覧履歴を収集する機能はありません。

6. 改定・問い合わせ

機能やデータの扱いが変わる場合、このポリシーを更新します。お問い合わせはChromeウェブストアの本拡張機能掲載ページに表示される開発者連絡先をご利用ください。
